Hands-on notes and Python exercises from my AI Engineer learning journey.

## Focus

- Python fundamentals
- REST APIs and JSON
- Pandas and data analysis
- LLM fundamentals
- OpenAI and Azure OpenAI
- Embeddings, vector search, and RAG
- AI agents and tool calling

## Repository structure

- `python-basics/` - Python lessons and practical exercises
- `ai-basics/` - AI and LLM lessons
- `SKILLS.md` - completed topics and learning roadmap
- `progress.md` - early learning progress

## Setup

Create and activate a virtual environment, then install the packages used by a
lesson as needed:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install pandas requests
```
